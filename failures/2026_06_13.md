# grey "waste money" clouds
> June 13th of 2026  

Recently had a pretty cool idea of making a program. The program's steps would be:

* Extract metadata from a PE file
* Run strings to extract present strings in the binary 
* See what libraries are loaded
* Run hexdump, xxd or other fun things parse put it into a cool format
* Look at some other cool stuff
* Send it into OpenAI API to see if there are any vulnerabilities in the PE
* Make the OpenAI slop machine do passovers on the binary, iterating to see  if anything is vulnerable

If the ouroboros of vibe found a vulnerability with confidence above the threshold, it would display the relevant ASM. After 30 minutes of vibecoding, I tested it against an intentionally obvious vulnerable program. The simple dimple outcome: even after 10 passes and with the threshold set to 30%, the pipeline of vibe still could not determine that the program was vulnerable.

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main() {
    int overflow_me = 5; // buffer gets overflown
    char buffer[256];
    
    printf("Hi enter your name\n");
    overflow_me = 10;
    scanf("%s", buffer);

    printf("[INFO] name %s, it has the length %d\n", buffer, strlen(buffer));

    char* hi = (char*) malloc(strlen(buffer)* sizeof(char));
    printf("[INFO] alloced string\n");
    memcpy(hi, buffer, strlen(buffer));

    

    printf("[INFO] memcopy done\n");
    // my payload made it print something like 150000000
    printf("overflow_me is suppose to be 10: %d\n", overflow_me); 
    return 0;
}
```

The buffer overflow payload was:
```bash
"(random stuff)...\x90\x90\x90\x90\x90\...\x90"
```

I am 100% sure **I did not** implement it correctly, mostly because I was not really the one doing it. I probably also did not vibe-prompt hard enough, as I do not usually do much of that. There are almost certainly a thousand better repos out there, but I wanted to experience the hyped-up vibe-coding prompt-engineering workflow that everyone keeps talking about.

PS: the src will not be released cuz it's bad
